# Basics of Python Notes

This file is a module-level revision sheet for the `Basics of Python` folder.

## Quick Revision

- `print()` displays output.
- Strings use quotes: `"..."` or `'...'`.
- `#` starts a comment.
- Variables are assigned with `=`.
- `input()` returns a string.
- `type()` shows the data type of a value.
- Python is dynamically typed.
- `int`, `float`, `str`, `bool`, and `None` are common data types.
- `len()` returns the length of a string or sequence.
- String methods like `.upper()` work only on strings.
