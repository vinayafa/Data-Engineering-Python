# Working With Strings Notes

This file is a module-level revision sheet for the `Working With Strings` folder.

## Quick Revision

- Strings can be combined with `+` or formatted with f-strings.
- `split()` breaks a string into a list.
- `strip()`, `lstrip()`, and `rstrip()` remove unwanted spaces or characters.
- `lower()` and `upper()` change case.
- `find()` locates the position of text inside a string.
- `startswith()` and `endswith()` check the beginning or end of a string.
- `in` checks whether text exists inside another string.
- `isalpha()` checks for letters only.
- `isnumeric()` checks for digits only.
- Indexing starts at `0` and slicing uses `start:end`.
- String repetition uses `"text" * n`.
