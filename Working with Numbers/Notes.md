# Working with Numbers Notes

This file is a module-level revision sheet for the `Working with Numbers` folder.

## Quick Revision

- `int`, `float`, and `complex` are the main numeric types used in this folder.
- `type()` shows the data type of a value.
- `int()`, `float()`, and `complex()` convert or create numeric values.
- Arithmetic operators: `+`, `-`, `*`, `/`, `//`, `%`, and `**`.
- Augmented assignment: `x += 1`, `x *= 2`.
- `abs()` returns absolute value.
- `round()` changes decimal precision.
- `math.floor()`, `math.ceil()`, and `math.trunc()` are different ways to remove or adjust decimals.
- `random.random()` gives a float from `0.0` to `1.0`.
- `random.randint(a, b)` gives a random integer between `a` and `b`.
- `is_integer()` checks whether a float is a whole number.
- `isinstance()` checks whether a value is a specific type.
