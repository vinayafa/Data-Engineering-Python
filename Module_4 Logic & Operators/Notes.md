# Module 4 Logic & Operators Notes

This file is a module-level revision sheet for the `Module_4 Logic & Operators` folder.

## Quick Revision

- Boolean values are `True` and `False`.
- `bool()` converts values based on truthiness.
- Empty values such as `0`, `""`, `None`, and empty containers are usually falsey.
- `any()` returns `True` if at least one value is truthy.
- `all()` returns `True` only if every value is truthy.
- `isinstance(value, type)` checks whether a value belongs to a type.
- `startswith()` and `endswith()` are useful boolean string checks.
